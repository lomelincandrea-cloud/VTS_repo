# Report coverage

Every field shown in the two reports, where it comes from, and whether it is captured today.

Status values:
- **captured now**: the manual and its forms already record it.
- **captured after Parts 1 and 2**: recorded once the COWORK 2026-11-19 manual changes are in use (committed 2026-11-19).
- **not captured**: nobody records it yet. The report prints "No data recorded" (never an empty or invented value). Each one has a reason.

Form codes: F03 Annual Plan, F04 Visit Sheet (checklist), F05 Corrective Maintenance Log, F06 Site History, F07 Site Card. Indicator IDs are in `indicators.json` (built from TOP-07.S05).
